# Webmin 漏洞复现合集

Webmin 是一款基于 Web 的系统管理工具，用于管理类 Unix 系统（如 Linux、Unix）的配置，具有 Web 图形化界面，广泛应用于服务器运维管理。

本目录收录了与 Webmin 相关的安全漏洞复现文档，涵盖远程命令执行等多种漏洞类型。
