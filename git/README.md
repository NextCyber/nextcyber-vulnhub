# Git 服务漏洞复现合集

Git 是分布式版本控制系统，支持 ssh、git、https 三种协议来传递项目。Git-shell 是 git 服务中重要的组成部分，允许用户通过 ssh 访问 git 仓库时执行受限的命令集。攻击者可以利用 GIT-SHELL 沙盒绕过漏洞，读取任意文件甚至执行任意命令。

本目录收录了与 Git 服务相关的经典漏洞复现文档。
