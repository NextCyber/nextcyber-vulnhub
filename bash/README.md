## 概述

Bash（Bourne Again Shell）是Unix系统和Linux系统的一种Shell（命令行环境），是目前绝大多数Linux发行版的默认Shell。bash 4.3 存在一处破壳漏洞（Shellshock），可导致远程代码执行。
