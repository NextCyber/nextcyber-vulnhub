# Fastjson 漏洞复现合集

Fastjson 是阿里巴巴公司开源的一款 JSON 解析器，其性能优越，被广泛应用于各大厂商的 Java 项目中。Fastjson 在解析 JSON 的过程中，支持使用 autoType 来实例化某一个具体的类，并调用该类的 set/get 方法来访问属性。通过查找代码中相关的方法，即可构造出一些恶意利用链。

本目录收录了与 Fastjson 相关的经典高危漏洞复现文档，涵盖反序列化导致任意命令执行等多种漏洞类型。
