# Aria2 漏洞复现合集

Aria2 是一个命令行下轻量级、多协议、多来源的下载工具（支持 HTTP/HTTPS、FTP、BitTorrent、Metalink），内建 XML-RPC 和 JSON-RPC 接口。在有权限的情况下，我们可以使用 RPC 接口来操作 aria2 来下载文件，将文件下载至任意目录，造成任意文件写入漏洞。

本目录收录了与 Aria2 相关的漏洞复现文档。
