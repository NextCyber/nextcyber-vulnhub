# kkFileView 漏洞复现合集

kkFileView是一款功能强大的文档预览解决方案，支持多种文件格式的在线预览，包括 Word、Excel、PPT、PDF、图片等。

本目录收录了与 kkFileView 相关的漏洞复现文档，涵盖 ZipSlip 远程命令执行等漏洞类型。
