# AppWeb 漏洞复现合集

AppWeb 是 Embedthis Software LLC 公司负责开发维护的一个基于 GPL 开源协议的嵌入式 Web Server。他使用 C/C++ 来编写，能够运行在几乎所有流行的操作系统上，主要为嵌入式设备提供 Web Application 容器。

本目录收录了与 AppWeb 相关的安全漏洞复现文档。
