# Cacti 漏洞复现合集

Cacti 是一款利用 RRDTool 数据存储和图形化功能的完整网络图形化解决方案，广泛应用于服务器监控与管理。在 Cacti 1.2.28 及以前版本中存在多处命令注入漏洞，允许已认证用户在 Web 服务器上创建任意 PHP 文件，从而可能导致远程代码执行。

本目录收录了与 Cacti 相关的经典高危漏洞复现文档，涵盖前台命令注入、后台 RRDTool 参数注入、SQL 注入等多种漏洞类型。
