# CMS Made Simple 漏洞复现合集

CMS Made Simple（CMSMS）是一个免费的开放源码内容管理系统，为开发人员、程序员和网站所有者提供基于网络的开发和管理功能。

本目录收录了与 CMS Made Simple 相关的安全漏洞复现文档，涵盖 SQL 注入、服务器端模板注入（SSTI）等多种漏洞类型。
