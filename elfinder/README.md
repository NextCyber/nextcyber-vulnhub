# elFinder

elFinder 是一个开源的 Web 文件管理器，提供了类似资源管理器的功能，支持文件上传、下载、复制、移动、删除等操作。它广泛应用于各种 CMS 和 Web 应用中作为文件管理组件。

## 漏洞列表

| CVE 编号 | 漏洞类型 | 危险等级 |
|----------|----------|----------|
| CVE-2021-32682 | ZIP 参数与任意命令注入 | 🔴 高危 |

## 影响版本

elFinder 2.1.49 及之前版本存在命令注入漏洞。

## 环境搭建

靶机启动后，访问 `http://your-ip:8080` 即可查看到 elFinder 的文件管理页面。
