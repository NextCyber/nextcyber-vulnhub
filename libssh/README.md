# libssh 漏洞复现合集

libssh 是一个提供 ssh 相关接口的开源库，包含服务端、客户端等。libssh 0.6.0 - 0.8.4 版本中存在服务端权限认证绕过漏洞，攻击者可以在认证成功前发送 MSG_USERAUTH_SUCCESS 消息，绕过认证过程，未授权访问目标 SSH 服务器。

本目录收录了与 libssh 相关的安全漏洞复现文档。
