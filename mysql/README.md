# MySQL 漏洞复现合集

MySQL 是美国 Oracle 公司研发的一套开源关系型数据库管理系统，支持 SQL 标准查询语言，广泛应用于 Web 应用、企业级系统、数据仓库等场景。

本目录收录了与 MySQL/MariaDB 相关的经典高危漏洞复现文档，涵盖身份认证绕过等多种漏洞类型。
