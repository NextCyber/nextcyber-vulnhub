# MySQL Vulnerability Reproductions

MySQL is an open-source relational database management system developed by Oracle Corporation, supporting SQL standard query language and widely used in Web applications, enterprise systems, data warehouses, and other scenarios.

This directory contains classic high-risk vulnerability reproduction documents related to MySQL/MariaDB, covering authentication bypass and other vulnerability types.
