# scrapyd 漏洞复现合集

scrapyd 是爬虫框架 scrapy 提供的云服务，用户可以部署自己的 scrapy 包到云服务，默认监听在 6800 端口。

本目录收录了与 scrapyd 相关的经典高危漏洞复现文档，涵盖未授权远程代码执行等多种漏洞类型。
