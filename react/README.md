# React 漏洞复现合集

React 是 Facebook 开发的用于构建用户界面的 JavaScript 库。React 2Shell 是 React Server Components（RSC）相关的一个未授权远程代码执行（RCE）漏洞，攻击者可通过构造恶意请求触发服务端反序列化/解码链路的问题，从而在服务器进程权限下执行任意代码。

本目录收录了与 React 相关的漏洞复现文档。
