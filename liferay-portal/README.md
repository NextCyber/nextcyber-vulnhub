# Liferay Portal 漏洞复现合集

Liferay Portal CE是一款用来快速构建网站的开源系统，以其灵活的插件架构和丰富的功能著称，广泛用于企业门户和协作平台。

本目录收录了与 Liferay Portal 相关的漏洞复现文档，涵盖 Java 反序列化远程命令执行等漏洞类型。
