# OpenTSDB 漏洞复现合集

OpenTSDB是一款基于Hbase的、分布式的、可伸缩的时间序列数据库，支持 HBase 存储，广泛应用于监控系统、物联网数据采集等场景。

本目录收录了与 OpenTSDB 相关的经典高危漏洞复现文档，涵盖命令注入等多种漏洞类型。
