# Redis 漏洞复现合集

Redis 是美国 Redis 公司研发的一套开源 Key-Value 数据库，支持内存存储、持久化、集群等，广泛应用于缓存、会话管理、消息队列等场景。

本目录收录了与 Redis 相关的经典高危漏洞复现文档，涵盖未授权访问、主从复制 RCE 等多种漏洞类型。
