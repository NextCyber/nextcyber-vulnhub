# Apache Log4j 漏洞复现合集

Apache Log4j是Apache组织的一个开源日志组件，广泛应用于Java应用程序的日志记录。Log4j支持通过SocketServer启动远程日志服务器，便于集中管理和分析日志数据。

本目录收录了与 Apache Log4j 相关的漏洞复现文档，涵盖反序列化远程命令执行等漏洞类型。
