# Metabase 漏洞复现合集

Metabase 是美国 Metabase 公司研发的一套开源数据分析平台，支持数据可视化、查询构建、仪表盘构建等功能，广泛应用于企业级数据分析和商业智能领域。

本目录收录了与 Metabase 相关的经典高危漏洞复现文档，涵盖任意文件读取、未授权JDBC远程代码执行等多种漏洞类型。
