# ImageMagick 漏洞复现合集

ImageMagick 是一款使用量很广的图片处理程序，很多厂商都调用了这个程序进行图片处理，包括图片的伸缩、切割、水印、格式转换等等。ImageMagick 6.9.2-10 版本存在命令执行漏洞，当用户传入包含『畸形内容』的图片时，可能触发命令注入。

本目录收录了与 ImageMagick 相关的安全漏洞复现文档。
