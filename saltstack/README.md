# SaltStack 漏洞复现合集

SaltStack 是基于 Python 开发的一套 C/S 架构配置管理工具，广泛应用于批量服务器配置、自动化运维等场景。

本目录收录了与 SaltStack 相关的经典高危漏洞复现文档，涵盖认证绕过、任意文件读写、命令注入等多种漏洞类型。
